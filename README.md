# 🏥 Farmacia POS - Sistema de Procesamiento de Transacciones (TPS)

## 📋 Descripción del Proyecto

**Farmacia POS** es un Sistema de Procesamiento de Transacciones (TPS) desarrollado para la gestión integral de una farmacia. El sistema automatiza el control de inventarios, punto de venta (POS), compras, proveedores, usuarios y generación de reportes, garantizando la trazabilidad de medicamentos por lotes y fechas de vencimiento.

El sistema fue desarrollado bajo una **arquitectura MVC (Modelo-Vista-Controlador)** utilizando **Python** con **Tkinter** para la interfaz gráfica y **SQLite** como base de datos relacional.

## 🚀 Instalación y Ejecución Automática (Windows)

### Requisitos previos
- **Python 3.11 o superior** instalado en el equipo
- Conexión a internet (para instalar dependencias)

### 🔧 Instalar Python (si no lo tienes)
1. Ve a: https://www.python.org/downloads/
2. Descarga **Python 3.11 o superior**
3. Durante la instalación, **MARCA la opción "Add Python to PATH"**
4. Reinicia tu PC

### ✅ Instalación automática
1. **Clona o descarga** este repositorio en tu PC
2. **Haz doble clic** en el archivo `setup.bat`
3. **Espera** a que la instalación automática termine
4. La aplicación se abrirá automáticamente
